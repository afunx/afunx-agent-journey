# Day 12 - 2026-09-29

## 今天学了什么

- 注意力计算公式：\(Q K^{T} / \sqrt{d_k}\)
- `torch.transpose(-2, -1)`：交换最后两个维度
- `torch.matmul`：维度大于 2 时，前面的维度保持不变，只对最后两维做矩阵乘

## 我现在的理解

- 注意力分数就是 Query 和 Key 的转置相乘，再除以 \(\sqrt{d_k}\)
- `transpose(-2, -1)` 用来得到 \(K^{T}\)：把最后两个维度对调
- 批量张量做 `matmul` 时，前面的维度当成一批批独立的矩阵，乘积发生在最后两维
